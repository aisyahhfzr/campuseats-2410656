# Week 1 reflection

Answer each question in 1–3 sentences, in your own words.

1. What is the difference between building a UI imperatively (plain DOM code) and declaratively (React)?
- In DOM, you manually write step by step instructions like create and update.
-In React, you describe what the UI should look like and React handles updating the DOM automatically. 

2. Why must a component name start with a capital letter?
-To distinguish between React components and HTML elements.

3. What does a fragment <>...</> do, and why not just use a <div>?
-To group multiple elements together without adding an extra  node

4. Name one benefit of splitting the UI into small components.
-Improves code reusability and makes your code easier to maintain, test, and debug.
